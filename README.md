## 📌 Sobre o projeto

Atividade de pesquisa do curso de Linguagem de Marcação do SENAI, com foco na estruturação, acessibilidade e estilização de páginas web para a confeitaria fictícia Doce Sabor.

## 🎯 Conteúdos estudados

- HTML5 semântico e acessibilidade.
- Formulários, links e `iframe`.
- Variáveis CSS e paleta de cores.
- CSS Grid e layout responsivo.
- Transições e efeitos visuais.

## 🛠️ Tecnologias

- HTML5
- CSS3
